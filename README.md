# Health-repo

A simple command-line hospital patient management application written in Python. It uses only the Python standard library and keeps its data in memory while the program is running.

## Run

```bash
python hospital.py
```

## Features

- Admit a patient and assign a patient ID
- Assign a doctor to a patient
- Generate a bill from the daily rate, stay length, and treatment charges
- Display an individual patient summary
- Print the list of admitted patients

Choose an option from the menu and follow the prompts. Patient IDs are assigned in admission order.
